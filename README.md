# Sanrentan -Nelo Edition- 完全パッケージ

63×89mm（角丸R3）カードゲーム一式。型抜きランド「知育カード定型」テンプレート
（card_chiiku_6389r3）準拠。

## フォルダ構成

### 01_入稿データ_CMYK/ ★これを入稿に使う
全11種・実寸69×95mm（塗り足し3mm込み）・CMYK・墨/グレーはK単色・全テキストアウトライン済み。

| ファイル | 内容 | 印刷枚数の目安 |
|---|---|---|
| sanrentan_odai_front.pdf | お題カード表（サンプル1種） | お題数ぶん差し替え生成 |
| sanrentan_odai_back.pdf | お題カード裏（PARTY RACE TICKET黒） | お題カードと同数 |
| sanrentan_answer_A〜G.pdf | 順位カード表 7種 | 各×プレイ人数 |
| sanrentan_rank_back.pdf | 順位カード共通裏（RANKING DECK） | 7×プレイ人数 |
| sanrentan_rules_haitou.pdf | 配当表（役一覧） | 4〜5枚（裏はお題裏を流用） |

### 02_編集用SVG/
全カードのベクターソース。Illustratorでそのまま開ける（アウトライン済み・フォント不要）。

### 03_生成スクリプト/
- build_cards_v5.py … お題カード表裏。`odai` と `opts` を差し替えて量産
- build_ag_cards.py … 順位カードA〜G
- build_rank_back.py … 順位カード共通裏
- build_rules_card.py … 配当表
- textpath.py … テキストアウトライン化ヘルパー（全スクリプトが依存）

実行: `python3 build_cards_v5.py` → SVG生成 → cairosvgでPDF化 →
GhostscriptでCMYK変換（手順は各履歴参照）。

### 04_プレビュー/
確認用画像（検版オーバーレイ: 赤=カット線63×89 / 青=文字切れ57×83）。

### 05_テンプレート原本/
card_chiiku_6389r3.ai（型抜きランド入稿テンプレート）。

## Illustratorでの入稿手順
1. 05のテンプレ.aiを開く（レイヤー: ガイド/トンボ/デザイン/カット）
2. 「デザイン」レイヤーに01のPDFを配置（ファイル→配置→埋め込み）
3. 整列パネルで水平・垂直中央（PDFは塗り足しサイズちょうどなのでガイドの69×95枠に一致）
4. ドキュメントのカラーモードがCMYKか確認（ファイル→ドキュメントのカラーモード）
5. 表・裏それぞれ別ファイルとして Illustrator CS6以下互換で保存

## 役（配当表の内容・公式準拠）
- サンレンタン 6点: 1〜3位の選択肢と順位がぴったり
- サンレンプク 4点: 1〜3位の選択肢が当たった
- ニレンタン 3点: 1位・2位の選択肢と順位がぴったり
- プクプク 2点: 選択肢が2つだけ当たった
- タン 1点: 1位の選択肢と順位が当たった
